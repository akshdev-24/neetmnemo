# NEETMONIC – NEET Biology Mnemonics & Revision Platform

A dedicated, student-friendly educational platform under parent brand **AKSHDEV** for **NEET UG Biology preparation**, featuring 1,180+ visual mnemonics, active recall cards, and chapter-wise study tools mapped 100% to NCERT Class 11 & Class 12 Biology (Botany & Zoology).

- **Production URL:** `https://neetmonic.akshdev.site/`
- **Class 11 Hub:** `https://neetmonic.akshdev.site/class-11-biology-mnemonics`
- **Class 12 Hub:** `https://neetmonic.akshdev.site/class-12-biology-mnemonics`
- **Parent Brand:** AKSHDEV
- **Curriculum:** NCERT Class 11 & 12 Biology (32 Chapters across 10 Units)
- **Target Exam:** NTA NEET UG (Biology Section: 360/720 marks)

## Features
- **1,180+ Handcrafted Biology Mnemonics:** Zero invented facts, strictly cross-referenced with NCERT textbooks.
- **10 NCERT Biology Units:**
  1. Diversity in Living World (Chapters 1–4)
  2. Structural Organisation in Animals and Plants (Chapters 5–7)
  3. Cell: Structure and Function (Chapters 8–10)
  4. Plant Physiology (Chapters 11–13)
  5. Human Physiology (Chapters 14–19)
  6. Reproduction (Chapters 20–22)
  7. Genetics and Evolution (Chapters 23–25)
  8. Biology and Human Welfare (Chapters 26–27)
  9. Biotechnology (Chapters 28–29)
  10. Ecology and Environment (Chapters 30–32)
- **Interactive Study Tools:**
  - Quick Revision Sprints (timed active recall decks)
  - Interactive Recall Quizzes with instant NCERT explanations
  - My Memory Shelf (client-side saved cards)
  - Streaks, XP and Unit Mastery Progress Tracker
  - Instant Search across all chapters, topics, and memory hooks
- **Full Policy & Trust Suite:** Dedicated About, Privacy Policy, Terms of Service, Disclaimer, and Contact pages.

## Development & Build
```bash
# Install dependencies
npm install

# Run locally
npm run dev

# Run Biology database integrity validation
node scripts/final-validate.js

# Build production bundle & generate sitemap.xml / robots.txt
npm run build
```
